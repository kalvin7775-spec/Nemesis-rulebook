01
遊戲概述
OVERVIEW — 你為什麼會死
STATUS — NOMINAL ▼

復仇女神號是一艘困在外太空的拖船。船員從低溫休眠中醒來，發現一具屍體、警報長鳴、未知生命形式已經登艦。每個人都有自己的祕密目標——而你必須在他們達成之前活著回家。

// 你的目標

遊戲開始時，每位玩家會抽到 兩張目標卡。當第一隻入侵者出現在主板時，你必須選一張保留，另一張永遠移出遊戲。

目標可能是「將船開往特定座標」「殺死特定怪物」「獨自逃生」「讓某位船員死亡」——是的，這是半合作遊戲。

// 你的對手

入侵者不是由任何玩家控制——它們由入侵者袋（Intruder Bag）的隨機抽取驅動。

它們很強。它們會繁殖。它們的卵會孵化。最糟的是：你可能已經被感染了。

// 核心張力

三條獨立計時齊頭並進——時間軌（船的航行）、自爆程序（緊急選項）、入侵者袋（怪物增長）。

你永遠手忙腳亂、永遠資源不足、永遠不知道下一張事件卡會把你的計劃撕成碎片。

▸ INTEL · 新手提示

第一次玩請選擇合作模式（co-op）而非競爭模式；先用基礎場景熟悉「噪音 → 抽袋 → 入侵者出現」的因果鏈，再開放目標卡的背叛機制。

02
遊戲設置
SETUP PROTOCOL — 9 個儀式
STATUS — PREP ▼

遊戲開始前的儀式：洗牌、發牌、把死人放進船艙。設置本身就是氛圍的一部分——當你把那枚藍色屍體標記放進低溫艙時，恐怖才正式開始。

// Part A · 場上設置（步驟 1–7）

  1. 展開主板基礎面（左上角紅箭頭朝上）。從電腦室、發動機室開始向外是一座迷宮。
  2. 放置房間磚：標 "2" 的磚牌洗勻、面朝下放在 "2" 格；剩下 "A1" 磚牌放在其他空格。每個房間放一枚探索標記面朝下。
  3. 放置座標卡：洗勻後面朝下排成航線。船的最終目的地未知，直到有人去電腦室破解。
  4. 逃生艙：依玩家人數揭示對應數量的逃生艙，每個逃生艙都有限制容量。
  5. 發動機：每具發動機隨機放一枚標記——可能正常，可能損壞。
  6. 入侵者袋：依劇本與玩家數放入指定的入侵者標記（包含幼蟲、成體、空白等）。
  7. 事件牌堆：洗勻備用。每回合結尾翻一張，多半不是好消息。

// Part B · 玩家設置（步驟 8–9）

  1. 角色設置每位玩家拿角色板、迷你模型、起始武器、彈藥、兩張目標卡、兩個支線任務標記、洗好的個人動作牌堆。
  2. 儀式性的最後一步把藍色屍體標記放進低溫休眠室（Hibernatorium）。它代表那個沒能醒過來的同伴。整局遊戲它都會躺在那裡。
TIP · 第一具屍體

「第一具屍體永遠是藍色的。當你打開低溫艙的門看到他時——記得，他不是你殺的。但接下來死的可能是。」

03
回合結構
TURN STRUCTURE — 兩個階段
STATUS — CYCLE ▼

每一輪由兩個階段構成。玩家階段你還有幻覺以為自己掌握全局；事件階段船會告訴你誰才是主人。

// PHASE I
玩家階段
  1. 補牌每位玩家從動作牌堆抽牌直到手牌 5 張。牌堆抽完就洗棄牌堆重組。
  2. 輪流行動從首位玩家開始順時針。每個玩家輪到時可執行最多 2 個動作，或選擇 PASS。
  3. 動作來源動作牌可以作為任何「基本動作」打出，也可以打出卡面上的特殊動作。
  4. 持續輪轉所有人都 PASS 後階段結束。已 PASS 的玩家不能再行動。
// PHASE II
事件階段
  1. 入侵者動作已在板上的所有入侵者依其行為卡執行行動。
  2. 火災結算所有火災標記造成 1 點傷害給該房間的入侵者。
  3. 翻開事件卡解析效果：時間推進、新威脅、設備故障、入侵者袋變化。
  4. 入侵者袋發展事件卡指示從袋中抽/添加標記。袋裡的成體越多，下次抽噪音越深噩夢。
  5. 首位玩家順移下回合首位玩家標記交給左手邊。
TIP · PASS 不是認輸

「PASS 不是認輸——是讓對手先暴露牌力。但若所有人都搶著 PASS，事件階段會更快來——而事件階段，是船的回合。」

04
玩家動作
ACTIONS — 12 種選擇，每回合只能 2 個
STATUS — PROTOCOL ▼

每張動作牌都可以當「基本動作」打。問題不是你能做什麼，而是你做不完什麼——每回合只有 2 個動作，而你想做的有 12 件。

MOVE 移動

移動到相鄰房間。穿過技術走廊需用卡牌數字符合的路徑。進入未探索房間會觸發探索流程。

1 ACTION
CAREFUL MOVE 謹慎移動

移動但不擲噪音骰。代價：消耗額外卡牌。當你知道隔壁有怪時，這是救命操作。

1 ACTION + 1 CARD
SEARCH 搜索

翻開所在房間的探索標記，可能是物品、線索，也可能是入侵者卵或屍體。

1 ACTION
SHOOT 射擊

對同房間或相鄰房間入侵者開火。消耗彈藥、擲攻擊骰。射擊會製造噪音。

1 ACTION + AMMO
MELEE 近戰

面對面與入侵者格鬥。低傷、易受傷，但不消耗彈藥也不製造噪音。

1 ACTION
ROOM ACTION 房間動作

使用房間內建功能：發射逃生艙、解密電腦、修發動機、自爆程序等。

1 ACTION
PICK UP / DROP 拾取放下

從房間拾起物品或屍體、放入背包。背包容量有限。

1 ACTION
TRADE 交易

與同房間玩家交換物品。也可以「丟給」對方一張感染牌——如果你恨他的話。

1 ACTION
CRAFT 製作

合成更強的物品。需材料 + 圖紙。後期決勝負的合成品都靠這個。

1 ACTION + ITEMS
FIRST AID 急救

消耗輕傷牌恢復狀態。重傷無法用一般急救處理。

1 ACTION + ITEM
OBSERVE 觀察

偷看相鄰房間的入侵者行為卡、未來事件。資訊就是命。

1 ACTION
PASS 過牌

結束你的玩家階段。不可反悔——此後直到下回合不能再行動。

FREE
TIP · 效率優先

「你做的每一個動作，都讓船的時鐘多走一格。最有效率的玩家，是知道什麼不做的玩家。」

05
入侵者圖鑑
HOSTILE LIFEFORMS — 5 種敵人
STATUS — CRITICAL ▼

沒有人知道它們從哪來。它們不溝通、不投降、不留俘虜。它們從通風管出現、從牆內爬出、從你以為已經清空的房間裡甦醒。

類型 威脅等級 行為特徵 備註
幼蟲 LARVA LOW 移動緩慢、攻擊力低，但會在玩家身上留下感染卵。 真正的危險是它的胃口——和繁殖速度。
爬行者 CRAWLER LOW 幼蟲的成熟型態，群體出現。基本攻擊但會疊加噪音。 單獨好對付，但很少單獨出現。
成體 ADULT MID 標準殺手型，會主動追擊噪音來源、開門、跨房間。 袋裡的成體越多，劇情越糟。
繁殖者 BREEDER HIGH 定期在房間產卵。卵會孵化成新的入侵者。 看到就要優先處理，或這船完了。
女王 QUEEN BOSS 劇本性 BOSS。極高生命、極高傷害、可能召喚援軍。 正常局不會遇到，遇到了就準備掛。

// 入侵者袋機制

每次玩家進入未探索房間、發出第二個噪音、或事件指示時，從袋中抽取入侵者標記。

  • 幼蟲/成體放到對應房間的遭遇位，掀開戰鬥
  • 空白標記什麼都沒發生——但要往袋裡加一個成體。袋越打越深。
  • 抽過的標記放回袋裡（除非劇本另有規定），所以袋的組成會變化。

// 弱點卡 WEAKNESS

每種入侵者有一張弱點卡，遊戲開始時未知。發現後，攻擊該類型造成額外傷害或無視護甲。

發現弱點需要：解剖屍體、查電腦資料庫、或某些事件卡。資訊共享與否——這是半合作的關鍵抉擇。

06
戰鬥與遭遇
COMBAT — 賭博，不是決鬥
STATUS — FATAL ▼

戰鬥不是決鬥——是賭博。你擲骰，它抽行為卡，沒人知道下一秒誰活著。最聰明的戰鬥，是你能逃跑的那一次。

// 遭遇流程 ENCOUNTER

  1. 觸發進入未探索房間、第二噪音、開有噪音的門，或事件指示。
  2. 抽袋從入侵者袋抽 1 個標記。
  3. 放置對應的入侵者模型出現在當前房間。
  4. 立即行動該入侵者立刻翻一張行為卡執行攻擊或追擊。

// 戰鬥解析 ATTACK

玩家攻擊：擲攻擊骰+ 武器修正。命中後造成傷害。

入侵者「反擊」：翻其遭遇牌組中的卡，由入侵者選擇最壞的對玩家執行。

射擊永遠製造噪音。近戰不會，但你會被打。

// 傷害與感染 — WOUND & CONTAMINATION

// 輕傷 LIGHT WOUND

抽一張輕傷牌放入手牌。它佔位、有負面效果，但可以被急救丟棄。

累積太多輕傷牌會壓垮你的手牌空間——你會慢慢失去行動能力。

// 重傷 SERIOUS WOUND

抽一張重傷卡。每張都有獨特死法條件（再受擊、進入特定房間、回合結束等）。

累積 2 張重傷 = 立刻死亡。一張重傷也可能直接觸發死亡條件。

≈ CONTAMINATION · 感染協定

某些攻擊（特別是幼蟲）會把感染卡（Contamination Card）洗進你的動作牌堆。它們和正常動作牌一樣抽出來，但效果是負面的——而且會越積越多。

到了遊戲後期，每次進醫療艙做掃描時，要從手牌與棄牌堆中翻出感染卡——超過閾值你會爆破出新的入侵者。是的，從你身體裡。

07
房間參考
ROOM REFERENCE — 來自說明書原文
STATUS — REFERENCE ▼

船上 16 個房間各自有獨特的「房間動作」。學會用這些動作，是把劣勢翻成勝利的關鍵。

// 標準房間 — 標 "2" 的房間磚

包含的房間有：巢穴、摧毀蟲卵、儲藏室、手術室、氣閘控制室、餐廳、指揮中心、引擎控制室、減壓艙門控制系統、監控室、佈滿粘液的房間、浴室等。每個房間磚正面顯示一個獨特的「房間動作」圖示——學會在對的時間到對的房間，是後期生存的關鍵。

// 特殊房間 — 開局即在主板上

// 駕駛艙 COCKPIT

檢查座標卡、修改目的地、啟動自爆程序。遊戲的「方向盤」——誰控制這裡，誰決定船的命運。

// 引擎室 ENGINE ROOMS

三個引擎室分別處理 1/2/3 號發動機。修復發動機、檢查運轉狀態。引擎全壞 = 船在原地飄。

// 休眠室 HIBERNATORIUM

遊戲中段「時間軌到藍格」後才能進入。合法的勝利條件之一——只要你能撐到那時、沒被感染、有人讓你進來。

// 逃生艙 ESCAPE PODS

用「房間動作」發射逃生艙——把自己（與背包中的物品/屍體）射出船外。容量有限。第一具死屍出現後自動解鎖。

▸ INTEL · 規劃路線

遊戲開局就要在腦中標出「最近的逃生艙在哪」「電腦室在哪」「醫療艙在哪」。每多走一格都是時間。
